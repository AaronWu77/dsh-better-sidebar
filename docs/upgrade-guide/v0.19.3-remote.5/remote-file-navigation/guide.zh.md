# 在所属会话内打开远端文件

[English](guide.md) | 中文

## 变更

配套 `0.19.3-remote.6` 与 Remote SSH `0.2.4-aaron.12-sidebar.6` 在 Better Sidebar 原生编辑器内打开对话文件链接。该原生编辑器启用时，Remote SSH 不启动外部编辑器，也不把文件地址换成 Windows 下载缓存地址。单独使用 Remote SSH 及其显式外部打开端点时，编辑器与下载行为保持不变。

产物文件操作使用来源会话，不依赖底部工作台的选中会话。原生目录打开保留目录意图，原生 Git 文件操作使用同样绑定会话的编辑器回调。Git 编辑器操作以服务端返回的会话 cwd 作工作区围栏，不再把 Windows 别名和 POSIX 文件路径比较；元数据等待或失败时，不允许受围栏保护的打开。Markdown 和经过清洗的 HTML 文件链接相对预览文档解析，不继承对话导航。跨文件的行号与章节片段不作为文件名，但公共打开接口不会定位这些片段。客户端服务报告已安装的包版本。

远端别名包含检查与失效路由拒绝保持启用。远端编辑器不会回退读取本地文件。此版本不优化大型工作区的文件名搜索延迟，也不启用远端 `sidebar_open` 工具。

## 迁移

1. 停止 Web 服务并备份当前 profile 文件。一起安装两个 `.6` 归档；不要混用配套版本，也不要在服务运行时替换文件。
2. 保留现有 SSH 映射和侧栏设置，启用 Better Sidebar 的编辑器标签。不需要迁移会话数据或删除缓存目录。
3. 按原有方式启动 Web 并刷新现有页面。在同一个远端任务中，先从文件树打开一个 README，再点击它的对话链接。两者都应显示远端内容，不出现 `Temp/dsh-remote-ssh/open-file` 地址或别名外路径错误。
4. 检查底部工作台未选中会话时的产物文件打开、原生目录打开和 Git 的编辑器操作。显式外部编辑器与下载应和应用内预览分开验收。
5. 如需回退，先停止 Web，重装两个 `.5` 归档，只恢复本次维护前的备份，再启动并刷新。不要删除别名、失效别名记录或会话数据。
